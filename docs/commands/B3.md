# `^B3` — Code 39 Barcode

## Overview

The `^B3` (Bar Code 39) command prints a Code 39 barcode. Code 39 is a discrete, self-checking barcode that supports uppercase letters (A–Z), digits (0–9), and the symbols `- . $ / + % SPACE`. It is commonly used in industrial and healthcare environments.

---

## ZPL Syntax

```
^B3o,e,h,f,g
```

| Parameter | Description | Values | Default |
|-----------|-------------|--------|---------|
| `o` | Orientation | `N` normal, `R` rotated 90°, `I` inverted, `B` bottom-up | `N` |
| `e` | Check digit calculation | `Y` / `N` | `N` |
| `h` | Barcode height in dots | — | — |
| `f` | Print interpretation line | `Y` / `N` | `Y` |
| `g` | Print interpretation line above | `Y` / `N` | `N` |

---

## PHP API

### `drawCode39()` — convenience wrapper

```php
$builder->drawCode39(
    float $x,
    float $y,
    float $height,
    string $data,
    bool $printData = false,
    Orientation $orientation = Orientation::NORMAL,
    int $size = 0
): void
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `$x` | `float` | X position in the current unit. |
| `$y` | `float` | Y position in the current unit. |
| `$height` | `float` | Barcode height in the current unit. |
| `$data` | `string` | Data to encode (uppercase A–Z, 0–9, `- . $ / + % SPACE`). |
| `$printData` | `bool` | Print human-readable text below the barcode. |
| `$orientation` | `Orientation` | Rotation of the barcode. |
| `$size` | `int` | Module width multiplier (1–9); `0` uses the printer default. |

### `drawBarcode()` — generic wrapper

```php
$builder->drawBarcode(Barcode::CODE39, $x, $y, $height, $data, ...);
```

## Examples

### Basic Code 39

```php
use Zpl\ZplBuilder;
use Zpl\Enums\Unit;

$builder = new ZplBuilder(Unit::DOTS);
$builder->drawCode39(5, 50, 20, 'ABC-123');
echo $builder->toZpl();
```

Output:

```
^XA
^FO5,50
^B3N,N,20,N,N
^FDABC-123^FS
^XZ
```

### With human-readable text

```php
$builder->drawCode39(5, 50, 20, 'ABC-123', true);
// Output: ^B3N,N,20,Y,N
```

### Rotated 90°

```php
use Zpl\Enums\Orientation;
$builder->drawCode39(5, 50, 20, 'ABC123', false, Orientation::ROTATED);
// Output: ^B3R,N,20,N,N
```

---

## Notes

- Code 39 does not require a check digit, but one can be added via the `e` parameter.
- The library fixes the check-digit parameter to `N` in the generated command.
- Data must use only the supported character set: `A–Z`, `0–9`, and `- . $ / + % SPACE`.
- Use Code 128 if you need lower-case letters or a more compact encoding.
- See [All Barcode Types](barcodes.md) for the full list of supported symbologies.
